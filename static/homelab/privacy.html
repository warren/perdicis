homelab privacy policy

homelab is used only by its owner, on the owner's own computer.

What it accesses

Only the Google data the owner approves on Google's consent screen, read-only. It never changes or deletes that data.

How the data is used

Only to show and summarise the owner's own information back to the owner. Processing happens on the owner's computer.

Sharing and storage

Data stays on the owner's computer. It is not sold, not shared with or transferred to third parties, and not used for advertising.

homelab's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
